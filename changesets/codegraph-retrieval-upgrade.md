代码图谱：新增 Kotlin、Swift、Dart、Scala、Elixir、Lua、Zig、R、Julia、Haskell、Objective-C、Groovy 十二门（六门随包、六门按需下载），以及 Terraform/HCL、Vue / Svelte / Astro 组件与 SQL / Prisma / GraphQL：组件读取其代码块（`<script>` 或 Astro 的 `---` frontmatter），SQL 识别 `CREATE TABLE/VIEW/FUNCTION` 及表间引用，Prisma 与 GraphQL 识别 model/type/enum 等块及其字段类型引用。`codegraph_context` 直接返回声明所在行的源码（带行号，可照着改），不再只给位置；检索支持按名称分词命中（`ruler` 能搜到 `diffRulerMarks`）与 `kind:` / `path:` / `lang:` / `name:` 过滤；索引会按 `.gitignore` 跳过文件、识别生成文件，并在设置页分别报告被忽略与生成的文件数；`codegraph_find` 的每一行都直接给出可复制的声明 id，同一个名字在类型、模型与迁移里各有一份声明时，不必再靠搜索挑一个来问影响面。`new Widget()` 这类构造调用现在计入引用（此前只有函数/方法调用算，导致最常用的类被报成「0 处引用」）。Scala、Elixir、Zig、Julia、Haskell、Groovy 六门改为按需下载（随内核发布提供、下载后校验哈希），安装包因此小了约 13MB；其余常用语言（含 Kotlin、Swift、Dart、Objective-C、Lua、R）仍随包提供。三件工具不再要求 web 侧的连接服务，因此没有窗口的会话（headless / TUI）里也能用。

Code graph: Kotlin, Swift, Dart, Scala, Elixir, Lua, Zig, R, Julia, Haskell, Objective-C and Groovy are now indexed (their grammars ship inside the plugin), as are Terraform/HCL, Vue, Svelte and Astro components and SQL, Prisma and GraphQL schemas (a component's `<script>` block and SQL's `CREATE TABLE/VIEW/FUNCTION` objects, plus which tables each file references); `codegraph_context` now returns the declaration's own source, line-numbered and ready to edit, instead of only its location; search matches a name's word parts (`ruler` finds `diffRulerMarks`) and accepts `kind:` / `path:` / `lang:` / `name:` filters; indexing honours `.gitignore`, recognises generated files, and reports the ignored and generated counts separately in settings; every `codegraph_find` row prints the declaration id to hand straight to `codegraph_impact`, so a name that is declared once per notation needs no search to disambiguate. A constructor call (`new Widget()`) now counts as a reference — it did not, which made the most-used class in a repository answer "0 call sites". Scala, Elixir, Zig, Julia, Haskell and Groovy download on request instead (shipped beside the kernel release, hash-verified), which takes ~13 MB out of the installer; every other common language — Kotlin, Swift, Dart, Objective-C, Lua, R included — still ships inside the plugin. The three tools no longer require the web-side connection service, so a session with no window (headless / TUI) can use them.
