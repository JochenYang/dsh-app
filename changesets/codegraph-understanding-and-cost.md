代码图谱插件：项目概览按量级计数、入口行不带行号并加一行顶层目录分布，同一会话 5 分钟内不因编辑重发；文件大纲与检索行带签名，列表默认不超过约 1,200 token 并在首行说明细度与裁剪；请求里点名了已索引文件或唯一声明的标识符时，在模型做计划前附上一份不超过 1,700 字符的声明摘要；`codegraph_impact` 的引用行标出被 import 收窄的（✓）、列出引用它的测试文件，并可用 `depth` 展开到 3 层调用方；检索一个全项目只声明一次的标识符后（含 `run_code` 里的检索），在结果后附一句声明位置；按生成文件跳过的文件数随每条工具答案报告；平均行长 ≥500 的文件按生成文件跳过；设置页新增「开关」块列出三个环境变量开关及当前状态，`/status` 报告每个项目的计数。记忆插件：会话日志解码库上移到仓库 `scripts/lib/`，与图谱插件共用（无行为变化）。
Code graph plugin: the project overview counts by magnitude, drops line numbers from entry rows, adds a top-level layout line and no longer re-sends itself within five minutes of an edit in a session; file outlines and find rows carry signatures, a list stays within about 1,200 tokens and its first line states the detail level and any cut; a request that names an indexed file or a uniquely declared identifier gets a declaration summary of at most 1,700 characters before the model plans; `codegraph_impact` marks import-narrowed references (✓), lists the test files that reference the symbol and takes `depth` to expand callers to three levels; a search for an identifier declared exactly once — inside `run_code` too — is followed by where it is declared; every tool answer reports how many files were skipped as generated output; files whose average line is 500 characters or more are skipped as generated; the settings page gains a switches block naming the three environment switches with their state, and `/status` reports per-project counters. Memory plugin: the session-log decoder moved to the repository's `scripts/lib/` and is shared with the graph plugin (no behaviour change).
