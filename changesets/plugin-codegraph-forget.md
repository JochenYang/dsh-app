设置页可以为每个项目删除代码图谱，释放它占用的磁盘空间——工作区里移除的项目不再只能靠手动找哈希目录清理。删除前需要在确认框里勾选确认，项目本身不受影响，下次有会话使用该项目时会重新建立图谱。
The settings page can now delete any project's code graph, freeing the disk space it holds — a project removed from the workspace no longer needs the hashed directory found by hand. The confirmation requires an acknowledgement before it runs; the project itself is untouched, and the graph is rebuilt the next time a session uses it.
