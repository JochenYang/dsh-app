演示文稿：skill 里多了一节设计系统——两个版式族怎么选、配色纪律（单 accent、面积上限、按「文字是否压在色上」判对比度）、数据大字报、图片取景、讲稿写进备注页、中文文案要求，以及导出前十条自检清单。新增品牌色换算：给一个 `#RRGGBB`，在 OKLCH 里换算成模板的六个颜色槽（背景/正文/accent/表面/次要/muted），用 WCAG 对比度做门禁（正文 ≥ 7:1、accent ≥ 3:1、次要与页脚 ≥ 4.5:1），任何被调整的地方都逐条报出；换算结果直接给出可粘贴的 `theme.colors` 块，模型不再自己算颜色。颜色与版式解耦：模板面板底部多一行「配色」，提供「模板自带」与十套命名配色（六套杂志风、四套瑞士风，含一套深色），带三格色卡预览；旁边可直接填品牌色（格式不对时按钮禁用并提示）。只换颜色、不换版式。模型也可用新工具 `ppt_set_colours` 把用户口头给的品牌色或选中的配色记到本会话；模式开着但还没定颜色时，skill 要求先问一次「有没有品牌色」。品牌色与配色都随会话的 PPT 模式保存，切换模板不会清掉；**关掉胶囊不丢配色**（关的是模式，不是这份 deck 的颜色），再开回来还在；PPT 模式没开时先给品牌色也会被记下，开模式即生效；「常规主题」（未选模板）同样带着这套配色。渲染也认这两个值：清单没写 `theme` 时按「品牌色 > 配色库 > 模板自带」补上，所以模型漏写也不会掉色（写了则以清单为准）。

Presentations: the skill gains a design-system section — how to choose between the two layout families, palette discipline (one accent, an area ceiling, contrast judged by whether text sits ON the colour), data slides, image framing, speaker notes in the notes field, Chinese copy rules, and a ten-item pre-export checklist. Brand-colour derivation is new: given one `#RRGGBB`, it produces the template's six colour slots (background / text / accent / surface / secondary / muted) in OKLCH and gates them on WCAG ratios (body ≥ 7:1, accent ≥ 3:1, supporting text ≥ 4.5:1), reporting every adjustment it had to make, and hands the model a pasteable `theme.colors` block instead of colour maths. Colour is now decoupled from layout: the template panel grows a 配色 row offering the template's own colours and ten named colourways (six magazine, four Swiss, one dark) with a three-pane swatch, plus a brand-colour field that disables the apply button while the value is malformed — colours change without touching the page geometry. A new `ppt_set_colours` tool records a brand colour or colourway the user states in conversation, and the skill asks once for a brand colour when the mode is on and no colours are set. Both values are stored with the session's PPT mode and survive switching templates; turning the capsule OFF keeps them (the switch turns the mode off, not the deck's colours), and a brand colour stated while the mode is still off is recorded and takes effect the moment the switch goes on. Rendering honours them as well: a manifest that writes no `theme` takes the session's colours (brand over colourway over the template's own), so a model that omits the block cannot silently drop the user's colour choice — a manifest that writes its own `theme` still wins.
