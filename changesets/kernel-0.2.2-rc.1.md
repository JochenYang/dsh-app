跟随内核线 0.2.2-rc.1。三十八个内核包逐个解包比对：34 个有改动、4 个逐字节相同，改动面主要是六种新语言的界面文案；我们 import 的 23 个包里 0 个符号丢失、15 个声明有变。真正的适配只有一处源码——`plugin-rewind` 的会话投影：`ProjectionDefinition` 改成两个泛型（折状态类型不再查表），`SessionProjectionStateMap` 已被删除，`register` 的返回值从 disposer 变成 `ProjectionHandle`（用它的 `dispose()` 收尾）。另有一处测试把 primitives 的 peer 版本写死在旧线上，改成读根 manifest 的当前线。还有一类新的依赖面：内核包开始把兄弟包声明成 peer（`dsh-scope`、`dsh-attachment`、`dsh-util-time`），而本仓按 `--legacy-peer-deps` 安装不装 peer，没有显式声明的插件会在建包或运行期找不到它们；已在这 12 个插件的 devDependencies 里补齐。CI 的 Node 从 22 提到 24.9（0.2.2 的 engines 下限，且构包会把运行中的 node 打进产物）。

Follow the 0.2.2-rc.1 kernel line. Unpacking all kernel packages: 34 changed, 4 byte-identical, and the bulk of the delta is six new UI locales. Of the 23 packages we import, no symbol disappeared and 15 declarations changed. Exactly one source adaptation was needed — `plugin-rewind`'s session projection: `ProjectionDefinition` now takes two generics (the fold's state is no longer looked up in a map), `SessionProjectionStateMap` is gone, and `register` answers a `ProjectionHandle` instead of a disposer, so teardown goes through its own `dispose()`. One test had pinned the primitives peer version to the old line and now reads the followed line from the root manifest. A new dependency shape also appeared: kernel packages declare their siblings as peers (`dsh-scope`, `dsh-attachment`, `dsh-util-time`), and this repo installs with `--legacy-peer-deps`, which installs no peers — so a plugin that reaches that code fails at bundle or load time unless it declares them; twelve plugins now do. CI's Node moves from 22 to 24.9, the engines floor of this line and the version the runtime build packs into the artifact. One build blocker came with the move: the lockfile reader matched kernel packages by path prefix, so npm's new nested copies of the vendored packages counted as a second kernel version and refused every runtime build — it now matches the package name, in the one place both the CLI and the test read.
